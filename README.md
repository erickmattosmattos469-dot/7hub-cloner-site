# 7HUB CLONER - Web Version

Uma ferramenta web para clonar servidores do Discord com facilidade.

## 🚀 Funcionalidades

- ✅ Clonagem completa de servidores Discord
- ✅ Suporte a canais, categorias e cargos
- ✅ Preservação de permissões
- ✅ Sistema de logs com rastreamento de visitantes
- ✅ Interface moderna e responsiva

## 📊 Sistema de Logs

O site inclui um sistema automático de logs que registra:
- 📱 Tipo de dispositivo (Desktop, Celular, Tablet)
- 💻 Sistema Operacional
- 🌐 Navegador utilizado
- 🔗 IP do visitante
- 🌍 País e Cidade
- ⏰ Data e hora do acesso

Todas as informações são enviadas para um webhook do Discord em tempo real.

## 🔧 Instalação Local

```bash
# Clonar o repositório
git clone https://github.com/erickmattosmattos469-dot/7hub-cloner-site.git
cd 7hub-cloner-site

# Executar servidor local
python3 -m http.server 3000
```

Acesse `http://localhost:3000` no seu navegador.

## 🌐 Deploy no Vercel

Este projeto está configurado para funcionar perfeitamente no Vercel:

1. Acesse [Vercel](https://vercel.com)
2. Conecte seu repositório GitHub
3. Clique em "Deploy"
4. Pronto! Seu site estará online
